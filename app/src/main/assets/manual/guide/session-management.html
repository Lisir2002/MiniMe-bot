会话管理

入口在「设置 → 数据与诊断 → 会话管理」。由于聊天界面和终端在工作期间强绑定单一工作区，跨工作区的全盘整理统一放在这里进行。

查看本地与远程会话

所有聊天会话与消息记录都保存在手机本地数据库中，即使当前处于本地模式（或尚未连接远程 SSH 服务器），你依然可以在这里看到：

  • 当前环境工作区：当前执行后端下的可用工作区（本机内部工作区、外部本地目录，或已连接的远程 SSH 工作区）。
  • 远程 / 离线历史工作区：曾经使用过的远程服务器路径、切换模式前的本地工作区，或已移除的外部目录。

顶部支持按「全部 / 当前环境 / 远程/离线」筛选，也支持输入关键词跨所有工作区搜索会话标题、工作区路径和历史消息内容。

阅读会话内容与切换打开

  • 点击任意会话可进入详情页，完整查看用户消息、AI 回复、可展开的思考过程以及工具调用记录（即使对应远程工作区当前离线也可只读查看与复制），并支持重命名、导出或删除。
  • 如果该会话属于当前环境可用工作区，可点击「在聊天中打开」，直接切到该工作区并继续对话。

跨工作区移动与批量整理

你可以通过以下方式调整会话所属的工作区：

  • 批量修改：点击右上角多选按钮（或长按会话选择「批量选择」），勾选一个或多个会话后点击底部「移动」选择目标工作区，也可点击「批量删除」一次清理多个会话。
  • 单条操作：长按任意会话打开操作菜单，可选择「移动到工作区」、置顶、重命名、导出或删除；进入会话详情页后也可直接移动所属工作区。

说明

  • 正在运行或尚有排队待发消息的会话需先停止后才能移动或删除。
  • 若移动的是当前正在查看的会话且目标属于当前可用工作区，应用会自动跟随切换到目标工作区。
  • 跨环境移动（如将本地会话移至离线远程路径）前会弹出确认提示，仅变更本地记录中的工作区归属，不会搬运磁盘文件。
