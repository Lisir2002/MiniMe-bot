# 08 安全设计

## 1. 信任边界

```text
信任：用户、控制面进程、用户自己的服务器
不信任：容器内执行内容、插件脚本、模型输出、上传文件、外部网络
```

容器不是安全边界之外的“可信环境”。  
容器内运行的是用户和 Agent 生成的命令，默认按不可信处理。

## 2. 端云边界

- App 不持有云端模型 Key 明文
- App 不直连容器
- App 不使用 SSH
- 正式环境 App 只通过 HTTPS / SSE / WebSocket 访问控制面；测试阶段可显式切到 IP+HTTP，并在界面持续标注风险
- 控制面数据库不暴露公网
- 容器不暴露入站端口

## 3. 密钥

- 云端凭据 AES-256-GCM 加密存储
- 主密钥 `/var/lib/minibot/master.key`，权限 0600
- 主密钥不进数据库、不进普通备份、不进环境变量
- 解密只在 Turn 期间，放进 `SecretLease`
- Key 不进容器、事件、日志、邮件、错误信息、prompt
- API 只返回 `hasSecret`
- provider 错误体脱敏后再落库

## 4. 文件路径

所有文件 API 路径必须：

1. 是相对路径
2. 规范化后仍在 workspace 内
3. 拒绝 `..`
4. 拒绝绝对路径
5. 符号链接目标越界拒绝
6. 写入用 `O_NOFOLLOW`
7. 不接受宿主路径

控制面读写宿主 workspace 时，必须做 realpath 校验，防止容器创建逃逸软链接。

## 5. 容器

- 不挂 Docker socket
- 不挂宿主根目录
- 不挂控制面数据库
- 不挂模型 Key
- 不挂其他容器卷
- 只挂 workspace / skills / plugins / tool-logs
- tool-logs 只读
- 容器内非 root 用户运行
- 容器不暴露入站端口

## 6. 工具执行

- 不在宿主执行工具命令
- 只通过 Docker Engine API 进容器
- 命令参数结构化，不拼宿主 shell
- 超时杀进程组
- 大输出落文件，限制事件 payload
- `tool.started` 先落库，崩溃后可识别“可能已执行”

## 7. 终端

- 只在容器内跑
- 不注入模型 Key
- 不做命令审批，终端就是用户自己操作
- WebSocket 必须带设备令牌
- 同一终端只允许一个连接
- 终端输出不进邮件、推送、会话事件
- 滚动缓冲有上限
- 第一版不录制终端

终端是高风险入口，必须要求：

- 设备已配对
- 容器存在且运行
- 用户显式打开
- 关闭后不保留 PTY

## 8. 插件

- 插件包上传后校验 manifest
- 解压路径防 Zip Slip
- 插件只能写自己的目录和 workspace
- 插件脚本只能在容器执行
- 插件不能读模型 Key
- 插件原生 Android 能力在云端不可用
- 插件安装记录服务器侧留痕
- 不自动执行未知插件安装脚本

## 9. API

- 单设备 Bearer token
- token 存 hash，不存明文
- 配对 token 一次性、短有效期
- 写接口幂等
- 速率限制
- 请求体大小限制
- 上传大小限制
- 错误信息不返回内部路径、SQL、密钥
- CORS 只允许 App 需要的最小范围

## 10. 通知

- 邮件不放聊天正文、命令全文、Key、文件内容
- 邮件深链不带设备令牌
- 审批不能在邮件里直接完成
- SMTP 密码加密存储
- 通知事件与投递状态可审计
- 失败不静默丢失

## 11. 供应链

- 官方镜像按 digest 拉取
- 镜像签名校验
- 生成 SBOM
- 漏洞扫描
- 基础镜像只来自官方 CI
- 用户自定义包只允许公开源
- 包安全由用户自担
- 平台只接受结构化包规格

## 12. 日志与审计

默认日志不记：

- 模型 Key
- 设备令牌
- SMTP 密码
- 完整 prompt
- 聊天正文
- 文件内容

可以记：

- request_id
- 设备 ID
- 容器 ID
- Turn ID
- 工具名
- 退出码
- 耗时
- token usage
- 错误码

敏感日志必须脱敏。

## 13. 资源安全

- 每容器 CPU / 内存 / 磁盘限制
- 并发 Turn 上限
- 并发命令上限
- 终端数量上限
- 上传大小上限
- 工具输出上限
- 磁盘配额告警
- 容器异常自动停止，不无限重启

## 14. 安全红线

任何一条不满足都不能上线：

- 云端 Key 不回传 App
- 容器不能访问 Docker socket
- 文件 API 不能越出 workspace
- 终端不能碰宿主
- 工具不能在宿主执行
- 邮件不能带敏感正文
- 控制面数据库不能暴露公网
